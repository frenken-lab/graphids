# CAN relationship pilot

Run `python scripts/mine_can_patterns.py --output OUTPUT_DIR` from the repository root. The runner reads the raw `set_01` through `set_04` CSVs under `GRAPHIDS_LAKE_ROOT/raw` by default. `--raw-root` overrides that directory. `--sets set_03 set_04` selects a subset of sets. `--normal-only` runs the selected normal partitions without attack diagnostics.

Each set uses a deterministic two reference, one calibration, one normal test assignment. When filenames include two accessory and two attack-free captures, the first of each type is a reference; the second accessory is calibration and the second attack-free is normal test. `assignment.json` records these roles and SHA256 hashes before attack scoring. The miner reads only the two reference captures. No graph snapshots or Graph-Mamba package are required.

The version 1 `catalog.json` contains the raw whole-ID event keys (`ID|arrival` and `ID|change`), patterns, ordered lag windows, per-reference support, completion rates, binomial standard-error estimates, shifted-control rates, source hashes, fixed settings, and candidate decisions. A sparse set of retained pairs bounds composition. At most three distinct keys and four ordered events form a pattern. A four-step cycle may return to the first key. Events from other IDs can occur between steps. These are predictive timing relationships, not decoded CAN semantics or causal edges.

Each `tables/*.jsonl` line contains a bin-close timestamp, fixed-capacity arrays and masks for IDs and relationships, a standalone pattern score and alert, and a per-ID timeout alert. The loader counts decreasing raw timestamps and stably orders frames by timestamp before deriving payload changes. Malformed payloads remain raw text for change detection; their exact character lengths and counts are reported. The tracker state is reset for every file. A prefix expires only after its lag deadline. The per-ID timeout comparison uses three times each reference ID's median positive interarrival gap. Alerts and rates in `report.json` are bin counts, not event-label recall. The report includes normal exposure, ID coverage, pattern stability, candidate rejection reasons, and runtime. Suppression files are diagnostics because their CSV labels do not specify when absent frames should have appeared.

The pilot is reference-conditioned. Whole-file hashes cannot establish independent source sessions. A catalog with no accepted patterns is valid and produces all-zero relationship arrays with masks set to zero; its coverage and normal exposure remain reportable. The catalog and fixed-slot arrays are the interface for a future Graph-Mamba snapshot builder.
